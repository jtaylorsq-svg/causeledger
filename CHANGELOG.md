# Changelog

## 0.1.0 candidate · 2026-10-25

Initial implementation, not yet publicly released.

- Local Python/SQLite corrective-action workbench with no runtime third-party dependencies.
- Fictional manufacturing examples covering washer omission and inspection illumination variation.
- Evidence review states, containment/disposition records, occurrence/escape cause verification, prevention/detection actions, implementation and effectiveness gates.
- Derived closure gaps, explicit reopen, evidence invalidation and optimistic concurrency.
- Append-only application events, consistent JSON export and offline integrity checks.
- Contributor/security guidance, domain/HTTP regression tests and configured CI.

### Known limitations / release holds

Public repository, remote CI and interactive browser QA are pending. One operator, loopback only. No authenticated identities, source-file attachments, JSON restore, hypothesis retirement or independent security review. Effectiveness acceptance is a human judgment against text criteria. Not a certified QMS or tamper-proof record system.
